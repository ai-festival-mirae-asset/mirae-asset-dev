## 1. 이 프로젝트가 만드는 것

**"금융상품 질문을 받으면, 확보한 데이터에 근거해서만 답하고, 모르는 것은 모른다고 말하는 API 서버"** 입니다.

- 대회 주최가 우리 서버 주소(`GET /answer`)로 질문을 프로그램으로 보내면, 우리 서버가 문항마다 답변 JSON(5개 항목, 전부 문자열)을 돌려줍니다. 공식 자료 기준 **일반 30문항(상·중·하 각 10) + 답변 불가 5문항**이며, 두 상품군을 함께 찾는 교차 질의도 나옵니다(주최 8/26 공지).
- 응답 시간: 주최는 기준을 공개하지 않습니다(8/26 공지 — 300초를 넘기면 미응답 처리, 늦은 응답은 점수 차등). 우리는 **내부 목표 15초**로 만들었고, 전 시험지 실측 최대 13.2초입니다.
- 채점: 소스코드 20점 + 기술제안서 40점 + 실전 답변 40점. **함정(답변 불가) 문항에 그럴싸하게 답하면 감점**이라, "잘 답하기"만큼 "안 답해야 할 때 거절하기"가 중요합니다. 데이터에 없는 수익률 전망·단정적 투자 추천도 금지.
- 일정: 제출 마감 **2026-09-06(일) 23:59**(이후 변경 = 실격) → 서버 **9/7~9/20 상시 가동**(이 기간 중 주최가 호출) → 예선 결과 10/1(예정) → 본선·멘토링 10/1~10/16 → 결선 10월(6팀, 발표+라이브 시연).
- 데이터 기준일: **8/26 재배포본 — 국내 2026-08-22 · 해외 2026-08-23**, 직접 수집한 ETF 구성종목은 2026-08-21. 그 이후 정보는 "모른다"가 정답입니다(07/11 구본은 주최 공지로 폐기).
- 제출물 3종 — ① 소스코드 + `requirements.txt` + 이 README(환경 구성·실행 명령어) + **온톨로지 TTL 5개 파일** ② 기술제안서(PDF) ③ 서버 주소 + **API 명세서**([API_SPEC.md](API_SPEC.md)). 규칙의 출처와 세부는 [ROADMAP.md](ROADMAP.md) §2~§3.

## 2. 시스템이 작동하는 방식 (질문 하나의 여정)

```
질문 → [1] 라우터: 무엇을 조회할지 계획 (규칙 우선, 복잡할 때만 AI 1번)
     → [2] 4개 채널로 조회: 표(SQL)·관계(그래프)·이름(키워드)·의미(벡터)
     → [3] 답변 검증: 나가기 직전 5중 검문 (함정이면 여기서 거절 확정)
     → [4] 답변 생성: 근거로 확인된 사실만 문장으로 (HyperCLOVA X)
     → 5필드 JSON 응답 (질문·답변·근거·과정 기록 포함)
```

예를 들어 "삼성전자가 포함된 ETF 알려줘"라고 물으면 — 라우터가 "삼성전자"를 종목코드 005930으로 연결하고, 그래프 채널에서 편입 ETF를 찾고, 표 채널에서 편입 비중·순자산을 붙여, 근거(출처·기준일)와 함께 답합니다. 반대로 "kimi 관련 상품 있어?"는 데이터 전체에서 일치하는 것이 없음을 확인하고 정해진 거절 문구로 답합니다.

주최가 필수로 정한 HyperCLOVA X 구간(질의 의도 분석 + 답변 생성)은 모든 질문이 예외 없이 거칩니다. 규칙만으로 답이 확정된 질문도 의도 확인 호출과 최종화 호출을 지나갑니다.

## 5. 설치와 실행 (환경 구성 · 실행 명령어)

사전 준비: **Python 3.12 이상**(서버 Ubuntu 24.04의 기본 Python이 3.12 — 개발 PC는 3.13으로 확인), git. 우리 프로그램은 세 덩어리입니다 — ① 코드(GitHub) ② 열쇠(CLOVA API 키 — 팀장이 따로 전달) ③ 재료(정제된 상품 데이터 — GitHub에 커밋돼 있음). 따로 받아야 하는 것은 ② 하나뿐입니다.

### 5.1 처음 받았을 때 (20분)

**1) 코드 받기** — 작업 브랜치는 `main`입니다.

```bash
git clone https://github.com/ai-festival-mirae-asset/mirae-asset-dev.git
```
```bash
cd mirae-asset-dev
```

이미 받아 뒀다면 `git pull`.

**2) 준비물 설치** (한 번만)

```bash
pip install -r requirements.txt
```

**3) 열쇠 넣기** — 비밀값은 `.env` 파일 하나로 관리합니다.

```bash
copy .env.example .env
```

맥·리눅스는 `cp .env.example .env`. 만들어진 `.env`를 메모장으로 열어 `CLOVASTUDIO_API_KEY=` 바로 뒤에 팀장이 보낸 키를 붙여넣고 저장합니다(`=` 앞뒤 띄어쓰기 금지, 따옴표 금지, 다른 줄은 비워 둠). 확인:

```bash
python config/env_loader.py
```

맨 아랫줄에 `CLOVA 호출 준비 완료.` 가 나오면 성공입니다. 운영체제 환경변수를 쓰던 사람은 그대로 둬도 됩니다(환경변수가 `.env`보다 우선).

**4) 데이터 만들기** — 2줄, 돈 안 듭니다. 원본 엑셀은 필요 없습니다(정제 결과가 저장소에 있음).

```bash
python storage/load_duckdb.py
```
```bash
python kg/build_kg.py
```

> 실행하지 말 것: `preprocessing/preprocess.py`(원본 엑셀 8개 필요 — 결과는 커밋돼 있음), `vector/build_index.py`(다시 만들면 임베딩 API 요금이 실제로 나감 — 고유 7,723건). 둘 다 원본 데이터가 갱신됐을 때만 팀장이 실행합니다. 정제를 다시 할 때는 원본을 repo 루트 `datasets/`에 두거나 `.env`의 `MIRAE_DATASETS`로 위치를 지정합니다.
> 옛 그래프 파일이 남아 있으면 서버가 켜질 때 "재생성 필요" 오류로 멈춥니다(조용히 틀리는 것보다 낫게 해 둔 것) — `python kg/build_kg.py`를 다시 실행하면 됩니다.

**5) 잘 되는지 확인**

```bash
python -m pytest tests/ -q
```

`... passed`가 나오고 `failed`가 없으면 정상입니다(약 1분, 돈 안 듦). 이 PC의 임시 폴더 권한 문제로 시험이 시작을 못 하면 `--basetemp=<쓰기 가능한 폴더>`를 붙입니다.

```bash
python engine/answer_cli.py "순자산총액 기준으로 국내 ETF 상위 5개 알려줘"
```

ETF 5개 목록이 나오면 설치 완료입니다.

### 5.2 서버 실행과 브라우저 질문 시험대 (추천)

```bash
python server/app.py
```

기동(약 1분) 후 브라우저에서 `http://localhost:8000/` 접속 → 질문 입력 → 답변·근거·처리 과정이 화면에 표시됩니다. 실제 평가와 동일한 경로(`GET /answer`)를 타므로, 여기서 보이는 것이 곧 채점자가 받는 응답입니다. HCX 호출이 포함되므로 질문당 소액의 API 크레딧이 들고, 요금 없이 켜려면 `python server/app.py --light`(AI 끄고 규칙 엔진만).

터미널 데모:

```bash
python engine/answer_cli.py "삼성전자가 포함된 ETF 알려줘" --kg kr_etf,constituents
```
```bash
python engine/answer_cli.py "kimi 관련 투자 상품 있어?"
```
