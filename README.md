# 미래에셋 AI Festival — 금융상품 질의응답 에이전트 (개인 브랜치 papuagigi)

> **처음 오셨다면 이 문서부터 읽으세요.** 모르는 용어가 나오면 [용어집(GLOSSARY.md)](GLOSSARY.md)에 전부 정리돼 있습니다.

## 1. 이 프로젝트가 만드는 것

**"금융상품 질문을 받으면, 확보한 데이터에 근거해서만 답하고, 모르는 것은 모른다고 말하는 API 서버"** 입니다.

- 대회 주최가 우리 서버 주소로 질문 35개(일반 30 + 함정 5)를 프로그램으로 보내면, 우리 서버가 문항마다 답변 JSON을 돌려줍니다.
- 채점: 소스코드 20점 + 기술제안서 40점 + 실전 답변 40점. **함정 문항에 그럴싸하게 답하면 감점**이라, "잘 답하기"만큼 "안 답해야 할 때 거절하기"가 중요합니다.
- 제출 마감 2026-09-06, 평가 2026-09-07부터. 데이터 기준일은 **2026-07-11 스냅샷**(그 이후 정보는 "모른다"가 정답).

## 2. 시스템이 작동하는 방식 (질문 하나의 여정)

```
질문 → [1] 라우터: 무엇을 조회할지 계획 (규칙 우선, 복잡할 때만 AI 1번)
     → [2] 4개 채널로 조회: 표(SQL)·관계(그래프)·이름(키워드)·의미(벡터)
     → [3] 답변 검증: 나가기 직전 5중 검문 (함정이면 여기서 거절 확정)
     → [4] 답변 생성: 근거로 확인된 사실만 문장으로
     → 5필드 JSON 응답 (질문·답변·근거·과정 기록 포함)
```

예를 들어 "삼성전자가 포함된 ETF 알려줘"라고 물으면 — 라우터가 "삼성전자"를 종목코드 005930으로 연결하고, 그래프 채널에서 편입 ETF 229종을 찾고, 표 채널에서 편입 비중·순자산을 붙여, 근거(출처·기준일)와 함께 답합니다. 반대로 "kimi 관련 상품 있어?"는 데이터 전체에서 일치하는 것이 없음을 확인하고 정해진 거절 문구로 답합니다.

## 4. 폴더 안내

```
├── preprocessing/    제공 데이터(엑셀) 정제 — 방법 설명은 PREPROCESSING_METHOD.md
├── external_data/    직접 수집·조사한 자료 — 구성종목 수집기, 각종 사전(등급·별칭·테마 등)
├── ontology/         상품·회사·지수의 관계 설계도 (finance.ttl — 제출 필수물)
├── kg/               지식그래프 만들기·조회 (build_kg.py / query_kg.py)
├── vector/           의미 검색 인덱스 만들기·조회
├── storage/          DuckDB 적재 (load_duckdb.py → storage/output/products.duckdb)
├── pipeline/         공용 부품 — 엔티티 사전, 근거(Evidence) 규격, 시간 정책, 테마 사전
├── engine/           엔진 본체 — 라우터, 채널 실행기, SQL 템플릿, 답변 조립, 데모 CLI
├── agent/            CLOVA(HCX) API 클라이언트 — 규정 준수 강제 장치 포함
├── config/           정책 파일 (해석이 갈리는 규칙의 스위치 — policy.json)
├── evalset/          자체 모의고사 105문항 (evalset_v1.jsonl)
├── tests/            자동 테스트 199개 (pytest)
├── infra/            NCP 서버 구축 가이드
└── datasets/         대회 원본 엑셀 8개 — 각자 로컬에만 두고 커밋하지 않음
```

## 5. 실행 방법

사전 준비: Python 3.13, `pip install -r requirements.txt` 수준의 표준 환경. 원본 엑셀 8개는 repo 루트 `datasets/`에 두거나 환경변수 `MIRAE_DATASETS`로 위치를 지정합니다. CLOVA 호출이 필요한 단계만 환경변수 `CLOVASTUDIO_API_KEY`가 필요합니다(키 값은 어디에도 기록 금지).

이미 만들어진 산출물(DuckDB 파일, 그래프 파일, 벡터 인덱스)이 저장소 작업 폴더에 있으면 1~4는 건너뛰고 5부터 하면 됩니다.

```bash
# 1) 데이터 정제 (원본 엑셀 → 정제 CSV. 몇 번 실행해도 안전)
python preprocessing/preprocess.py

# 2) DuckDB 적재 (정제 CSV → storage/output/products.duckdb)
python storage/load_duckdb.py

# 3) 지식그래프 생성 (→ kg/output/*.nt)
python kg/build_kg.py

# 4) 의미검색 인덱스 생성 (CLOVA API 키 필요 — 이미 생성돼 있으면 생략)
python vector/build_index.py --all

# 5) 전체 자동 테스트 (약 15초)
python -m pytest tests/ -q

# 6) 데모: 질문 하나를 전 과정에 통과시켜 보기 (터미널)
python engine/answer_cli.py "순자산총액 기준으로 국내 ETF 상위 5개 알려줘"
python engine/answer_cli.py "삼성전자가 포함된 ETF 알려줘" --kg kr_etf,constituents
python engine/answer_cli.py "kimi 관련 투자 상품 있어?"
```

### 직접 질문을 입력해서 시험해 보기 (추천)

서버를 켜고 브라우저에서 **질문 시험대**를 엽니다:

```bash
python server/app.py
```

기동(약 1분) 후 브라우저에서 `http://localhost:8000/` 접속 → 질문 입력 → 답변·근거·처리 과정이 화면에 표시됩니다. 실제 평가와 동일한 경로(`GET /answer`)를 타므로, 여기서 보이는 것이 곧 채점자가 받는 응답입니다. HCX 호출(계획 수립·문장 생성)이 포함되므로 질문당 소액의 API 크레딧이 들고, 개발용으로 가볍게 켜려면 `python server/app.py --light`(AI 끄고 규칙 엔진만 — 크레딧 0원).
