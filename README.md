## 1. 이 프로젝트가 만드는 것

**"금융상품 질문을 받으면, 확보한 데이터에 근거해서만 답하고, 모르는 것은 모른다고 말하는 API 서버"** 입니다.

- 대회 주최가 우리 서버 주소(`GET /answer`)로 질문을 프로그램으로 보내면, 우리 서버가 문항마다 답변 JSON(5개 항목, 전부 문자열)을 돌려줍니다. 공식 자료 기준 **일반 30문항(상·중·하 각 10) + 답변 불가 5문항**(세부 수는 변경 가능), 문항당 **60초 이내 응답 권장**(우리 목표 15초, 실측 2.3~9.7초).
- 채점: 소스코드 20점 + 기술제안서 40점 + 실전 답변 40점. **함정(답변 불가) 문항에 그럴싸하게 답하면 감점**이라, "잘 답하기"만큼 "안 답해야 할 때 거절하기"가 중요합니다. 데이터에 없는 수익률 전망·단정적 투자 추천도 금지.
- 제출 마감 **2026-09-06 23:59**(이후 변경 = 실격) → 서버는 **9/7~9/20 상시 가동**(이 기간 중 주최가 호출) → 예선 결과 10/1(예정) → 본선·멘토링 10/1~10/16 → 결선 10월(6팀, 발표+라이브 시연). 데이터 기준일은 **2026-07-11 스냅샷**(그 이후 정보는 "모른다"가 정답).
- 제출물은 3종 — ① 소스코드 + `requirements.txt` + 이 README(환경 구성·실행 명령어) + **온톨로지 TTL 5개 파일** ② 기술제안서(PDF) ③ 서버 주소 + **API 명세서**([API_SPEC.md](API_SPEC.md)). 규칙의 출처와 세부는 [ROADMAP.md](ROADMAP.md) §2~§3.

## 2. 시스템이 작동하는 방식 (질문 하나의 여정)

```
질문 → [1] 라우터: 무엇을 조회할지 계획 (규칙 우선, 복잡할 때만 AI 1번)
     → [2] 4개 채널로 조회: 표(SQL)·관계(그래프)·이름(키워드)·의미(벡터)
     → [3] 답변 검증: 나가기 직전 5중 검문 (함정이면 여기서 거절 확정)
     → [4] 답변 생성: 근거로 확인된 사실만 문장으로
     → 5필드 JSON 응답 (질문·답변·근거·과정 기록 포함)
```

예를 들어 "삼성전자가 포함된 ETF 알려줘"라고 물으면 — 라우터가 "삼성전자"를 종목코드 005930으로 연결하고, 그래프 채널에서 편입 ETF 229종을 찾고, 표 채널에서 편입 비중·순자산을 붙여, 근거(출처·기준일)와 함께 답합니다. 반대로 "kimi 관련 상품 있어?"는 데이터 전체에서 일치하는 것이 없음을 확인하고 정해진 거절 문구로 답합니다.

## 5. 실행 방법

사전 준비: Python 3.13, `pip install -r requirements.txt` 수준의 표준 환경. 원본 엑셀 8개는 **1번(데이터 정제)을 직접 돌릴 때만** 필요합니다 — 정제 결과(`preprocessing/processed/`)가 저장소에 커밋돼 있어 팀원은 2번부터 시작하면 됩니다. 정제를 다시 할 때는 원본을 repo 루트 `datasets/`에 두거나 `.env`의 `MIRAE_DATASETS`로 위치를 지정합니다.

### 처음 받았을 때 — 설정 파일(.env) 만들기

> **팀원이 처음 설치한다면 [SETUP.md](SETUP.md) 를 보세요.** 코드 받기부터 데이터 넣기까지 순서대로 안내합니다. 아래는 요약입니다.

CLOVA API 키 같은 비밀값은 `.env` 파일 **하나로** 관리합니다. 저장소를 처음 받았다면 다음 세 줄이면 끝납니다.

```bash
copy .env.example .env          # Mac/Linux 는  cp .env.example .env
# .env 를 메모장으로 열어 CLOVASTUDIO_API_KEY= 뒤에 팀에서 받은 키를 붙여넣고 저장
python config/env_loader.py     # 제대로 들어갔는지 확인
```

마지막 줄에서 `CLOVA 호출 준비 완료.` 가 나오면 됩니다. 터미널을 껐다 켤 필요도, 운영체제 환경변수를 따로 등록할 필요도 없습니다.

| 알아둘 점 | 내용 |
|---|---|
| 키 값 전달 | 카카오톡 단톡방·GitHub·스크린샷 금지. 비밀번호 관리 도구나 팀 비공개 페이지로 전달합니다. |
| 커밋 안전 | `.env`는 `.gitignore`로 막혀 있어 실수로 올라가지 않습니다. 커밋되는 건 값이 빈 `.env.example`뿐입니다. |
| 기존 방식 | 예전처럼 운영체제 환경변수(`setx`)를 쓰던 팀원은 그대로 두면 됩니다. **운영체제 환경변수가 `.env`보다 우선**이라 충돌하지 않습니다. |
| 서버 배포 | NCP 서버에서는 `.env` 대신 실제 환경변수로 주입합니다. 위 우선순위 덕분에 개발용 `.env`가 운영 값을 덮어쓰지 않습니다. |
| 추가 설치 | 없습니다. `config/env_loader.py`는 파이썬 표준 기능만 씁니다. |


이미 만들어진 산출물(DuckDB 파일, 그래프 파일, 벡터 인덱스)이 저장소 작업 폴더에 있으면 1~4는 건너뛰고 5부터 하면 됩니다.

```bash
# 1) 데이터 정제 (원본 엑셀 → 정제 CSV) — 결과가 커밋돼 있으므로 원본이 갱신됐을 때만 실행
# python preprocessing/preprocess.py

# 2) DuckDB 적재 (정제 CSV → storage/output/products.duckdb)
python storage/load_duckdb.py

# 3) 지식그래프 생성 (→ kg/output/*.nt)
python kg/build_kg.py

# 4) 의미검색 인덱스 — 실행에 필요한 2개 파일은 저장소에 커밋돼 있으므로 보통 생략한다.
#    다시 만들면 임베딩 API 크레딧이 실제로 소모된다(해외ETF 5,567건 호출).
#    원본 데이터가 갱신됐을 때만 실행한다.
# python vector/build_index.py --all

# 5) 전체 자동 테스트 (약 15초)
python -m pytest tests/ -q

# 6) 데모: 질문 하나를 전 과정에 통과시켜 보기 (터미널)
python engine/answer_cli.py "순자산총액 기준으로 국내 ETF 상위 5개 알려줘"
python engine/answer_cli.py "삼성전자가 포함된 ETF 알려줘" --kg kr_etf,constituents
python engine/answer_cli.py "kimi 관련 투자 상품 있어?"
```

### 직접 질문을 입력해서 시험해 보기 (추천)

서버를 켜고 브라우저에서 **질문 시험대**를 엽니다:

```bash
python server/app.py
```

기동(약 1분) 후 브라우저에서 `http://localhost:8000/` 접속 → 질문 입력 → 답변·근거·처리 과정이 화면에 표시됩니다. 실제 평가와 동일한 경로(`GET /answer`)를 타므로, 여기서 보이는 것이 곧 채점자가 받는 응답입니다. HCX 호출(계획 수립·문장 생성)이 포함되므로 질문당 소액의 API 크레딧이 들고, 개발용으로 가볍게 켜려면 `python server/app.py --light`(AI 끄고 규칙 엔진만 — 크레딧 0원).
