# 제약조건 개선 2차 구현 및 평가 보고서

## 범위와 해석

1. **한글/영문 상품명 색인**
   - `alias_dictionary.csv` 중 검증된 국내 ETF 브랜드 행만 사용한다.
   - 투자 은어·테마 연상어는 상품 존재 근거로 자동 치환하지 않는다.
   - 구 브랜드는 현재 스냅샷의 브랜드로 연결한다(예: KBSTAR→RISE, KINDEX→ACE).
2. **판매상태와 당사판매여부 분리**
   - `sale_yn='판매중'`: 현재 판매상태.
   - `thco_sale_yn='Y'`: 당사판매여부.
   - 당사에서 현재 판매 중인 상품은 두 조건을 동시에 충족해야 한다.
   - `thco_sale_yn` 결측을 타사 판매로 간주하지 않는다. 타사 판매사 식별 요청은 필드 부재로 거절한다.
3. **위험등급 상품군에 국내채권 포함**
   - `kr_bond.drv_risk_grade` 1~6만 집계하고 0/결측은 제외한다.
   - 국내채권은 전체 마스터, 국내 ETF·ETN은 active, 공모펀드는 전체 마스터 범위임을 답변에 명시한다.
   - 해외 ETF는 위험등급 필드가 없어 부분 답변으로 유지한다.
4. **answer / partial / refuse 경계**
   - 근거가 충분하면 answer.
   - 분리 가능한 일부 조건만 지원하면 partial + 미지원 조건 명시.
   - 핵심 값·개체·시점·필드가 확인 불가능하면 refuse.
   - 조회 조건 일치 0건은 거절이 아니라 명시적인 0건 answer로 처리한다.
