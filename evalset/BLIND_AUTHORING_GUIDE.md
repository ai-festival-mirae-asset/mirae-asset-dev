# 블라인드 출제 안내 — 팀원용 (1쪽, 8/26)

> **누구에게**: papuagigi 브랜치의 에이전트를 "우리 규칙을 모르는 사람"의 눈으로 시험해 줄 팀원(kyungrae).
> **왜**: 자체 생성 문제는 만든 사람의 습관을 닮는다. 사람이 낸 다양한 문장이 자동 생성기가 못 찾는 구멍을 찾는다(8/26 조사 — 출제자 정렬 3단계).

## 부탁하는 것

| 난이도 | 문항 수(권장) | 기준 |
|---|---|---|
| 하 | 6~10 | 조건 하나로 찾는 단순 조회 |

| 상 | 6~10 | 여러 단계를 거쳐야 하는 질문(예: "○○를 편입한 ETF 중 순자산 1위 상품의 운용사는?") |
| 답변 불가 | 2~5 | 데이터에 없어서 "확인할 수 없습니다"가 정답인 질문 |

## 꼭 지켜 주세요 (블라인드 원칙)

1. **보지 말 것**: `engine/`·`evalset/`(이 파일 제외)·PLAN §4·§5 — 우리 규칙·기존 문항·정책을 본 상태로 내면 시험 가치가 사라집니다.
2. **봐도 되는 것**: 제공 데이터가 무엇인지(아래 요약), 공식 예시(아래), 본인의 금융 상식.
3. **말투는 자유** — 존댓말·반말·붙여쓰기·오타 섞임·구어체 전부 환영. 실전 채점자가 어떤 말투일지 모르는 게 핵심입니다.
4. **특정 이름을 반복하지 말 것** — 같은 상품·종목으로 여러 문항을 만들지 말고 다양하게.
5. 문항마다 **정답 근거 한 줄**을 메모해 주세요(예: "국내ETF 마스터의 위험등급 컬럼", "만든 질문이라 데이터에 없음 — 답변 불가가 정답"). 채점표로 바꿀 때 씁니다.
