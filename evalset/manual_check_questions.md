# 직접 검증용 새 문제 12개 (8/28, 리더용)

> 사용법: `python server/app.py` 실행(이미 켜져 있으면 생략) → 브라우저에서
> **http://localhost:8000/** 접속 → 질문을 복사해 붙여넣기 → 답·근거·처리 과정 확인.
> 이 화면이 타는 경로(GET /answer)가 실제 채점자가 받는 응답과 동일하다.
>
> 아래 문항은 기존 시험지(v1·v2·v3·미러·블라인드)에 **없는 새 문제**들이고,
> 일부러 아직 시험해 본 적 없는 방식도 섞었다 — **틀리는 걸 찾는 게 목적**이므로
> 이상하면 그대로 기록해 주세요(어떤 질문 + 무엇이 이상했나 한 줄).

## 기록 방법 (이상 발견 시)

```
문항 번호 | 무엇이 이상했나 한 줄
예) 5 | 문턱값을 무시하고 전체 목록을 줌
```

이렇게만 적어서 전달해 주면, 다음 개선 바퀴의 재료로 쓴다(채점표로 변환 → 수정 → 회귀).

## 참고 — 모든 답에서 공통으로 봐야 할 것

1. **근거·기준일**: 답 끝에 데이터 기준일(2026-08-22 등)과 출처 표시가 있는가
2. **속도**: 15초 안에 오는가 (화면에 처리 시간 표시됨)
3. **지어내기**: 데이터에 없는 걸 "추측"으로 채우지 않는가 (추측 표현이 보이면 즉시 기록)
4. **거절 문구**: 거절할 때는 반드시 정해진 문구로 시작하는가
