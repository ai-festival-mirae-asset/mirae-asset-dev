### 3.1 세션 만료가 HTTP 400 으로 나타난 사건 — 8/13 실측 (해결)

- **증상**: 1초 간격 수집 중 **776번째 요청(시작 ~26분 후)부터 전부 HTTP 400**. 문서화된 만료 신호(`LOGOUT` 문자열)가 아니어서 요청량 제한으로 오인하기 쉽다.
- **원인 확정**: 25분 냉각 후에도 400 지속 → **사용자가 재로그인해 새 쿠키 발급 → 즉시 정상**. 즉 IP 차단이 아니라 **세션 만료(만료된 JSESSIONID 는 400 반환)**. KRX 웹 세션은 API 호출만으로는 갱신되지 않고 ~25분 내외에 만료되는 것으로 보인다.
- **교훈**: **400 = 쿠키 재추출이 1순위 해법**(냉각 대기 불필요). 장시간 수집은 세션 만료를 전제로 분할 재개한다.
- **대응(수집기에 내장)**: ① probe가 HTTP 오류를 구분 보고 ② 수집 중 연속 실패 10회(기본, `--max-consec-fail`)면 즉시 중단 — 만료 세션으로 무의미한 요청을 계속하지 않는다. 수집분은 보존되고 **쿠키 갱신 후 같은 명령으로 재개(resume)**된다.
- **쿠키 재추출 절차**: KRX 재로그인 → [13108] 조회 → F12 > Network > `getJsonData.cmd` 의 Cookie 전체 복사 → `krx_cookie.txt` 덮어쓰기 (2장과 동일).

### 5.1 해외 상장 ETF 구성종목 — 소스 조사 결과 (8/13)

- **주 소스 후보 확정: 미국 SEC EDGAR Form N-PORT** — 미국 등록 펀드·ETF 전체의 **포지션 단위 보유내역**(구조화 XML, 2019.10~). 월별 보유내역을 분기마다 제출·공개(직전 분기 말월 외 ~60일 지연)하므로, 지금 공개분으로 **2026년 3~5월 as-of 보유내역 확보 가능 = 기준일(7/11) 이전 ✓ 규정 적합**(as-of 를 근거에 명시). 무료·직접 접근(EDGAR rate limit ~10req/s, User-Agent 필수) — 상용 API 불필요.
- **매핑 경로**: EDGAR `company_tickers_mf.json`(펀드 티커→CIK/시리즈) ↔ 우리 마스터 `pd_itm_no`(티커형 — OVS·BBSC.K·ARKQ.K 등 실측) 조인. 접미사(.K/.O 등 거래소 표기) 정규화 필요.
- **범위 한계**: N-PORT 는 미국 등록분만 — 비미국(UCITS 등) 상장 ETF 는 매핑 실패분으로 집계해 커버리지 명시(운용사 공시는 종목별 제각각이라 전수 불가).
- **착수 판단 게이트(보류 사유)**: 5,600종 파이프라인은 구축 비용이 큼. **S2 본공사(Router·Answer Validation·API 서버) 우선**, N-PORT 는 ① 주최 문의(해외ETF 구성종목 출제 여부) 답변 ② 105문항 실측에서 해외 구성 질의 비중 확인 후 착수 결정. 국내 상장 ETF 의 해외 주식 편입(34,931건)이 이미 상당 부분을 커버한다.
